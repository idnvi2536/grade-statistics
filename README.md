# 成绩统计分析

读取学生成绩表（CSV 文件），自动完成各科统计与总分排名，生成文字统计报告和平均分柱状图。

## 功能

- 读取 CSV 成绩表，自动清洗空行和非数字成绩
- 统计各科：平均分、最高分、最低分、及格率（≥60 分）
- 计算总分并自动排名，打印总分前 5 名
- 报告保存为 `成绩统计报告.txt`
- 自动生成各科平均分柱状图 `各科平均分.png`

## 环境要求

- Python 3.10 及以上
- 依赖库：pandas、matplotlib

安装依赖：

```bash
pip install -r requirements.txt
```

## 使用方法

1. 将成绩表保存为 `students.csv`，放在本脚本同一文件夹，格式如下（第一行为表头）：

```csv
姓名,语文,数学,英语
张伟,88,92,79
王芳,72,65,88
```

2. 运行：

```bash
py 成绩统计分析.py
```

3. 运行后在文件夹内查看：
   - `成绩统计报告.txt`：文字版统计结果
   - `各科平均分.png`：平均分柱状图

## 自定义科目

如果表格里的科目不是语文/数学/英语，修改脚本顶部这一行即可：

```python
SUBJECTS = ['语文', '数学', '英语']
```
